Four visible stages

1 · Intake

Two synthetic events and one approved USD per-call rule are copied into the private bundle.

2 · Recompute

The verifier checks every file hash and recomputes the input fingerprint, revision, counts and metrics.

3 · Review

Identity gaps and discrepancy classes remain visible. Classification is not causal attribution.

4 · Decide

The buyer owns acceptance, dispute or renewal. The usage-only replay leaves this decision UNPROVEN.

Run it locally

From the buyer-ledger/ directory:

period_dir="$(mktemp -d)"
python3 -m buyer_ledger reproduce build \
  --input examples/replayable-period/events.jsonl \
  --period 2026-10 \
  --rule-map examples/replayable-period/rule-map.json \
  --out "$period_dir/private" \
  --data-classification synthetic

python3 -m buyer_ledger reproduce verify "$period_dir/private"
python3 -m buyer_ledger reproduce publish "$period_dir/private" \
  --out "$period_dir/public" --by synthetic-fixture-reviewer
python3 -m buyer_ledger reproduce verify "$period_dir/public"
python3 -m buyer_ledger reproduce proof "$period_dir/private" \
  --out "$period_dir/proof" --by synthetic-fixture-reviewer

Synthetic data only. Publishing writes a local public copy; it does not upload anything. The copy contains manifest.json, template.json, index.html and public-share.json. A new task created from the template defaults to confidential. The Proof projection allowlists manifest and aggregate replay fields, excluding source paths and row-level subjects: replay without private inputs is UNAVAILABLE, and external acceptance is UNCHECKED.

What closes the next evidence gap?

This fixture establishes synthetic usage replay only. It does not establish a buyer’s disposition or a realized correction. A real period should add three separate records:

RecordWhat it establishes
Evidence sufficiencyWhich charge, delivery and coverage conclusions can be reviewed, and which remain UNPROVABLE
Buyer dispositionAccept, request evidence, request remediation, dispute or defer; the named buyer decides outside the replay verdict
Follow-up and second useAny separately observed supplier response or corrected record, plus whether another period is reviewed
